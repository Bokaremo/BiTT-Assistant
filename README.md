# BiTT Assistant | مساعد معلم التقنية

تطبيق ويندوز لتنظيم مجلدات طلبة مادة تقنية المعلومات، استيراد قوائم الطلبة، توزيع الأجهزة، إعداد استمارات المشاريع وبطاقات أعمال الطلبة، والتقارير.

## تنزيل وتشغيل

نزّل إصدار Windows من صفحة **Releases** وشغّل ملف التثبيت أو النسخة المحمولة. لا يحتاج التشغيل إلى Python. قد يتطلب تشغيل التطبيق كنافذة مستقلة توفر WebView2؛ ويمكنه فتح الواجهة في المتصفح عند عدم توفره.

## بناء التطبيق من المصدر

1. ثبّت Python 3.11 أو أحدث وInno Setup 6 أو 7 على Windows.
2. شغّل `build-public.bat`.
3. ستجد نسخة المجلد والنسخة المحمولة والمثبت داخل `dist`.

السكربت يبني النسخة العامة للمعلمين فقط. ملفات وميزات نسخة الماستر الخاصة غير مدرجة في هذا المستودع.

## الخصوصية

يعمل التطبيق محليًا على جهاز المعلم، ولا يرفع قوائم الطلبة إلى خدمة سحابية. احرص على حماية ملفات الطلبة ومجلدات التخزين وفق سياسات المدرسة.

## الدعم والإبلاغ عن مشكلة

استخدم قسم تواصل المطور داخل التطبيق، وأرفق لقطة شاشة وخطوات إعادة المشكلة دون إظهار بيانات طلاب غير لازمة.

## الترخيص

هذا المستودع منشور للاطلاع والتوزيع. لم يرفق ترخيص يمنح حقوق إعادة استخدام الشيفرة أو تعديلها؛ تواصل مع صاحب المشروع للحصول على إذن.

## رفع المصدر من موجه الأوامر

بعد رفع الملفات يدويًا إلى المستودع، فك ضغط حزمة المصدر على جهازك وشغّل `publish-to-github.bat`. سيستنسخ المستودع إلى مجلد مجاور، يطابق ملفات النسخة العامة، ثم يرفع أي تغييرات. عند أول commit سيطلب اسم صاحب التعديل وبريد GitHub المرتبط بحسابه. سجّل الدخول في نافذة GitHub إذا طلب Git ذلك.
